# Beatscript

Learn to code by making music and art, free, in your browser.

Beatscript is an open-source learning platform for teenagers and
adults. Write a few lines of code and instantly hear a rhythm or
see a drawing. No account, no install, no tracking.

## Why
Most coding tutorials are abstract. Beatscript teaches programming
through sound and visuals, in Romanian, English and Russian,
and runs on low-end phones and old laptops.

## Features (planned)
- Live code editor with instant audio/visual preview
- Guided tracks: Music with Code, Drawing with Code
- Share and remix creations via a link
- Lessons as plain text files, easy for teachers to contribute
- All data stays in your browser

## Run locally
npm install
npm run dev
